# REQ-0009: Dependency and security maintenance

- Status: Active
- Related ADR: None (bot-authored PRs, traceability requirement)

## Requirement

Ensure all dependency updates, including those from automated tools (Dependabot, Copilot), are tracked, audited, and linked to a traceability requirement. Bot-authored PRs must reference a requirement and pass security scan validation.

## Acceptance criteria

- All bot-authored dependency PRs (Dependabot, Copilot) reference REQ-0009 in their body
- `pr-links.yml` validates that every PR, including bot PRs, has a requirement reference
- Security scan job (`security-scan.yml`) passes before PR merge
- Dev dependencies (`requirements-dev.txt`) are included in audit scope
- Coverage gate ratchets toward 70% on each merge to `main`
- Test reports (JUnit, coverage) are saved in `testrpts/` and committed to `main` only
