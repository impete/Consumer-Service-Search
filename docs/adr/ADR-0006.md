# ADR-0006: GitHub Actions CI/CD with open source governance

- Status: Accepted
- Date: 2026-10-04

## Context
The repo should be contributor-friendly while keeping quality gates.

## Decision
Use GitHub Actions with DCO, CODEOWNERS, PR templates, and branch protection.

## Consequences
Positive: strong governance with light process. Negative: some maintainer overhead.
