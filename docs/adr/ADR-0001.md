# ADR-0001: HTTP REST between API and search service

- Status: Accepted
- Date: 2026-10-04

## Context
A Node.js API and a Python search service must communicate with low operational complexity.

## Decision
Use HTTP REST for phase 1. Keep gRPC as a future option if latency demands it.

## Consequences
Positive: easy debugging and local development. Negative: more serialization overhead than gRPC.
