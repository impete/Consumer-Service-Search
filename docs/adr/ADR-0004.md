# ADR-0004: Starting core data entities

- Status: Accepted
- Date: 2026-10-04

## Context
The MVP needs search and recommendation but not user activity tracking.

## Decision
Phase 1 entities: ServiceProvider, Category, Location, Review/Rating (deferred). No user activity tracking.

## Consequences
Positive: simpler MVP and compliance posture. Negative: personalization deferred.
