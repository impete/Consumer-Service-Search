# ADR-0007: Docker Compose locally, AWS ECS for the pilot

- Status: Accepted
- Date: 2026-10-04

## Context
Local testing on Mac/Linux and an AWS pilot are needed, with Azure/self-hosted later.

## Decision
Docker Compose for local development; AWS ECS for the pilot; Azure/self-hosted as placeholders.

## Consequences
Positive: simple local workflow, realistic pilot. Negative: some drift between environments.
