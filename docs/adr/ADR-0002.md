# ADR-0002: PostgreSQL full-text search with Elasticsearch migration path

- Status: Accepted
- Date: 2026-10-04

## Context
Providers must be retrievable by category, keyword, and location with minimal setup.

## Decision
Use PostgreSQL full-text search in phase 1; document Elasticsearch/vector options for scale.

## Consequences
Positive: low complexity, good MVP fit. Negative: may need tuning as data grows.
