# ADR-0008: Dual Apache 2.0 / MIT license

- Status: Accepted
- Date: 2026-10-04

## Context
The project should be enterprise- and contributor-friendly.

## Decision
License the project under Apache 2.0 or MIT, at the user's option.

## Consequences
Positive: flexible adoption. Negative: slight legal complexity.
