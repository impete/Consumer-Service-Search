# ADR-0003: Real-time recommendation engine

- Status: Accepted
- Date: 2026-10-04

## Context
Users search by service type, location, radius, and ranking preference and expect fast results.

## Decision
Implement ranking in the Python search service with Redis caching. Target 750-1500ms.

## Consequences
Positive: fast iteration on ranking logic. Negative: needs performance tuning and caching.
